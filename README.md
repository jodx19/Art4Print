# Art4Print | آرت فور برينت 🎨
> **مكتبتك في أي مكان — Your Library. Anywhere.**

[![Live Demo](https://img.shields.io/badge/demo-live-brightgreen.svg)](#) 
[![Tech Stack](https://img.shields.io/badge/tech-HTML5%20%7C%20CSS3%20%7C%20JS-blue.svg)](#)

**Art4Print** is a premium, high-converting landing page designed for a professional printing and binding library located in Minya, Egypt. It features a modern UI/UX with smooth animations, modular architecture, and a focus on university students and professionals.

---

## 🌟 Features | المميزات

### 🇸🇦 Arabic (العربية)
- **تصميم بريميوم**: واجهة مستخدم عصرية تعتمد على أحدث معايير الـ UI/UX.
- **متجاوب بالكامل**: يعمل بكفاءة عالية على جميع الأجهزة (موبايل، تابلت، ديسكتوب).
- **حركات انسيابية**: استخدام الـ Intersection Observer لتقديم حركات ظهور احترافية.
- **نظام ألوان مخصص**: هوية بصرية قوية تعتمد على تدرجات البنفسجي والمجنتة والسيان.
- **تواصل فوري**: ربط مباشر مع خدمة الواتساب لسهولة الطلب.

### 🇺🇸 English
- **Premium Design**: Modern UI based on the latest design trends.
- **Fully Responsive**: Optimized for Mobile, Tablet, and Desktop.
- **Smooth Animations**: Uses Intersection Observer for high-performance entrance effects.
- **Custom Identity**: Strong visual brand using Violet, Magenta, and Cyan gradients.
- **Instant Contact**: Direct integration with WhatsApp for seamless ordering.

---

## 🏗️ Technical Stack | التقنيات المستخدمة

- **Frontend**: HTML5, Vanilla CSS3, Javascript (ES6+).
- **Typography**: [Cairo](https://fonts.google.com/specimen/Cairo) (Arabic) & [Playfair Display](https://fonts.google.com/specimen/Playfair+Display) (Display).
- **Icons**: [Tabler Icons](https://tabler-icons.io/).
- **Architecture**: Modular separation (HTML/CSS/JS) for scalability.

---

## 📸 Sections | أقسام الصفحة

1. **Sticky Navigation**: Glassmorphism effect with blur filter.
2. **Hero Section**: Animated orbs and shimmer text effects.
3. **Marquee Ticker**: Infinite scrolling brand strip.
4. **Brand Identity**: Visual showcase of colors and typography.
5. **Services Grid**: 6 interactive cards with gradient-reveal hover states.
6. **Special Offer**: Dark-themed section with "Price Showcase".
7. **How it Works**: 4-step process guide.
8. **Testimonials**: Social proof from university students.
9. **Contact**: WhatsApp integration and order form.
10. **Footer**: Detailed site map and copyright info.
